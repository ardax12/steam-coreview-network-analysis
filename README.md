# steam-coreview-network-analysis

## Dataset

This project uses the Steam Co-Review Network dataset created by Luke Steuber.

The dataset connects Steam games based on shared user reviews. An edge between
two games represents users who reviewed both games, and the edge weight
represents the number of shared reviewers.

Original dataset:
https://github.com/lukeslp/steam-network-data
